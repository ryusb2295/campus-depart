# 나갈시간

수업 시작 시간은 아는데 집에서 몇 시에 나가야 하는지는 매번 다시 계산하게 됨. 특히 지하철 시간까지 맞추려면 더 귀찮아서 만들었음. 대구 지하철로 통학하는 상황을 기준으로 작업 중.

👉 [앱 열어보기](https://ryusb2295.github.io/campus-depart/)

## 지금 되는 것

- 요일별 수업 등록하고 한 주 시간표로 보기
- 첫 수업에 맞춰 출발할 시간 계산하기
- 현재 위치 주변 지역과 가까운 역 확인하기
- 현재 위치를 출발지로 적용해서 역까지 걷는 시간 반영하기
- 하루만 휴강 처리하거나, 수업 시간표 백업하기

예를 들어 월요일 첫 수업이 10시 30분이면 역까지 걷는 시간, 열차 이동시간, 강의실까지 걷는 시간과 여유시간을 빼서 나갈 시각을 보여줌. 학교 근처에 있어서 출발역과 도착역이 같으면 열차를 타지 않는 도보 이동으로 계산함.

## 아직 아쉬운 점

- 역까지 걷는 시간은 GPS와 역 좌표 사이 직선거리로 추정함. 실제 골목길이나 횡단보도는 모름.
- 강의실 위치를 직접 아는 건 아니라 역에서 강의실까지의 시간은 기본값을 씀.
- 연결한 열차 데이터는 **운행 시간표**임. 실제 열차 지연이나 몇 분 뒤 도착하는지 알려주는 실시간 정보는 아님.
- 환승 경로는 아직 계산 못 함.
- GitHub Pages에서는 열차 조회용 서버가 돌아가지 않아서 시간표 자동 조회가 안 됨. 화면과 위치 기능은 확인할 수 있음.

출발시간은 참고용으로 봐야 함. 실제 등교할 때는 역 안내나 운영기관 시간표도 확인하는 게 맞음.

## 사용한 데이터

- [국토교통부 TAGO 지하철정보 API](https://www.data.go.kr/data/15098554/openapi.do): 역별 열차 시간표
- [철도 데이터 포털 대구교통공사 역위치 자료](https://data.kric.go.kr/rips/M_01_01/detail.do?id=213): 가까운 역 찾기
- [BigDataCloud 주소 조회](https://www.bigdatacloud.com/docs/free-api/free-reverse-geocode-to-city-api): 현재 위치의 시·구·동 수준 지역 이름

위치를 누르면 브라우저가 권한을 요청함. 지역 이름 조회에는 현재 좌표가 BigDataCloud로 전송됨. 도로명주소까지 나오지는 않음. 출발지로 적용한 좌표는 사용 중인 브라우저에 저장됨.
