# 나갈시간

대학생 수업 시간표에 맞춰 출발시간을 역산하는 React 19 + Astryx PWA.

## 실행

Node.js 20 이상에서 `npm ci`, `npm run dev`. 배포 빌드는 `npm run build`, 계산 검증은 `npm test`.

TAGO 자동 조회를 사용하려면 `.env.example`을 `.env.local`로 복사해 `TAGO_SERVICE_KEY`를 채우고 개발 서버를 다시 시작하세요. 프로덕션에서는 같은 환경변수를 Node 서버에 설정하고 `npm run build` 후 `npm start`로 실행합니다. GitHub Pages는 정적 호스팅이라 `/api/transit` 서버가 없습니다. Pages 배포에서 자동 조회를 사용하려면 별도로 배포한 API 서버 주소를 `VITE_TRANSIT_API_URL`로 빌드 시 지정해야 합니다.

## 구현 범위

- 수업 추가/수정/삭제, 시간 중복 방지, 주간 시간표
- 날짜별 첫 수업 선택, 하루만 휴강 및 취소
- 도보/승강장/수업 전 여유시간을 포함한 출발 역산
- 열차를 놓친 경우 다음 열차 및 지각 시간 계산
- 기기 저장, JSON 백업/복원, 서비스 워커와 오프라인 앱 셸

## 데이터 한계

TAGO 지하철정보 API의 역 검색·역별 시간표 조회를 서버에서 수행합니다. 공공데이터포털에서 해당 API 활용 신청 후 받은 일반 인증키를 `.env.local`의 `TAGO_SERVICE_KEY`에 입력하세요(`.env.example` 참고). 키는 브라우저로 전달하지 않습니다. 서버는 역 이름과 호선을 정확히 맞춰 역 ID를 선택하고, 운행일·방향으로 출발역 시간표를 조회합니다. 키가 없거나 제공처가 오류를 반환하면 자동 계산을 하지 않습니다. 설정에서 직접 입력한 열차시각을 대신 사용할 수 있습니다. 도착은 두 역 사이 정차역 수로 추정한 이동시간으로 추정하며, 환승·행선지별 종착역 검증·공휴일 자동 판별은 지원하지 않습니다. 초기 수업은 사용자가 제공한 이미지의 8개 수업입니다. **계산 결과를 실제 통학 전에 운영기관 시간표와 대조하세요.**

연결 대상은 https://www.data.go.kr/data/15098554/openapi.do 입니다. 시간표 API는 실시간 도착정보가 아닙니다. 출발역 시각과 예상 이동시간으로 도착을 추정합니다. 실제 도착역 시각과 동일 열차를 연결하는 기능은 아직 구현되지 않았습니다.

PWA 설치와 브라우저 알림 권한에는 HTTPS 환경이 필요합니다. 앱을 열어 둔 동안 출발 알림을 예약할 수 있습니다. 앱을 닫거나 기기가 절전 상태에 들어간 뒤의 푸시는 지원하지 않습니다. 기본 알람처럼 정확한 시각 알림을 보장하지 않습니다.

## 모바일 UI 및 위치

아이폰·갤럭시를 위한 세로 단일 레이아웃, 하단 탭, 요일 선택 시간표, 수업 입력 바텀시트와 safe-area를 적용했습니다. 수업 데이터 저장 키를 새 버전으로 구분하여 제공된 시간표가 처음 표시됩니다. 이전 버전의 저장 데이터는 삭제하지 않습니다.

오늘 화면의 ‘출발 기준’에서 ‘현재 위치 확인’을 누르면 브라우저 권한을 요청합니다. 현재 위치의 시·구·동 수준 지역 이름과 가장 가까운 대구 지하철역, 직선거리 기반 예상 도보시간을 보여줍니다. 지역 이름은 [BigDataCloud의 클라이언트 주소 조회 API](https://www.bigdatacloud.com/docs/free-api/free-reverse-geocode-to-city-api)를 사용하며, 이 조회를 위해 좌표가 해당 서비스로 전송됩니다. 도로명과 건물번호는 제공하지 않습니다. ‘평소 출발지로 저장’을 선택한 경우에만 좌표를 이 브라우저에 저장합니다. 위치 거부·타임아웃·HTTPS 미지원 안내와 저장 좌표 삭제가 가능합니다.

통학 탭의 ‘현재 위치로 찾기’를 누르면 가까운 역을 선택하고 역까지의 예상 도보시간을 출발 계산에 적용합니다. 역 좌표는 [철도 데이터 포털의 대구교통공사 역위치 자료](https://data.kric.go.kr/rips/M_01_01/detail.do?id=213)에서 가져왔습니다. GPS 오차가 300m를 넘으면 자동 선택하지 않습니다. 실제 보행로·건물 출입구·강의실 위치는 반영되지 않으며 현재 위치 좌표는 통학 경로에 저장하지 않습니다. 위치가 바뀌면 버튼을 다시 눌러야 합니다.

휴대폰에서 PC 개발 서버를 확인하려면 같은 네트워크에서 `npm run dev -- --host 0.0.0.0`을 실행하고 터미널의 로컬 네트워크 주소로 접속합니다. HTTP의 LAN 주소에서는 위치 확인과 PWA 설치가 제한되므로 실제 기기 위치 검증은 HTTPS 배포가 필요합니다.

검증: 프로덕션 빌드와 자동 계산 테스트를 실행했습니다. 실제 휴대폰 GPS 수신과 보행 경로는 검증하지 않았습니다. 푸시는 구현하지 않았습니다.
